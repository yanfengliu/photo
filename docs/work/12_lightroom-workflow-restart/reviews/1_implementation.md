The additional findings are:

1. **P2 — Sanitization moves valid rotated crops.** At [core/src/develop/geometry.rs:204](crates/core/src/develop/geometry.rs:204), the center is clamped using unrotated half-width and half-height. On a square image, a crop with `cx=0.16, cy=0.5, width=0.4, height=0.02, angle=45°` has all four corners inside the image under the existing `corners`/`fits` contract at line 133. The new sanitizer nevertheless changes `cx` to `0.20`. Both private-settings and Camera Raw reads invoke this sanitizer, changing the composition on reload and allowing the next save to persist that change. The in-memory calculation confirmed the corners fit. [crop.rs:459](crates/xmp/tests/crop.rs:459) only generates centers inside unrotated bounds, so its randomized round-trip test misses this case.

2. **P2 — The format gate does not pin serialized mask-kind names.** [core/src/develop/format_tests.rs:130](crates/core/src/develop/format_tests.rs:130) records string values only at the root. `MaskShape` uses a nested `"kind"` discriminator, so changing its serialized value from `"linear"` to `"linear_gradient"` leaves the hash unchanged. Keeping `"linear"` as a deserialization alias would preserve old fixtures while allowing incompatible new output under format 1. An older build then treats these settings as unreadable rather than newer; the F10 fallback can replace them. The in-memory probe produced identical recorded paths for those two payloads. The test at line 144 therefore does not enforce its stated compatibility boundary.

3. **P2 — A retargeted symlink escapes concurrent-save detection.** [xmp/src/file.rs:104](crates/xmp/src/file.rs:104) resolves the caller’s path once, before every retry. If `photo.xmp → A.xmp` is atomically retargeted to `B.xmp` while the replacement is prepared, all subsequent reads still check `A.xmp`; line 123 overwrites `A.xmp` and reports success while `photo.xmp` reads `B.xmp`. This can occur before the final comparison, outside the documented comparison-to-rename window. [files.rs:231](crates/xmp/tests/files.rs:231) tests stationary links only; no test covers retargeting.
