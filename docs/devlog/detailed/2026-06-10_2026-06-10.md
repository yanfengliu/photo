## 2026-06-10 11:45 — 7x faster test suite via optimized dev dependencies (commit E, v0.1.4)

- Action: Added `[profile.dev.package."*"] opt-level = 2` to Cargo.toml after isolating the slow-suite cause: `decode_raw_image_applies_orientation_metadata` alone took 99.9s solo because rawler's `develop_intermediate` is pathologically slow in unoptimized builds even on a 24x12 synthetic DNG. With dependencies optimized (photo itself stays opt-level 0), that test drops to 11.8s and the full 298-test suite drops from ~105s to ~14.4s.
- Reviewer comments: deferred to the consolidated end-of-task multi-CLI review (commit G).
- Result: All four gates green; suite 7x faster locally and in CI.
- Reasoning: Test fixtures were already tiny, so the cost was per-call fixed overhead inside the dependency — a profile override is the standard zero-behavior-change fix and beats `#[ignore]` (which would silently drop RAW coverage) or fixture surgery (fixtures were not the bottleneck).
- Notes: Trade-off: cold builds compile dependencies with optimization (one-time cost, cached by CI's rust-cache); debugging into dependency internals loses fidelity, which we don't do.
