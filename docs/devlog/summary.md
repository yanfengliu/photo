# Devlog Summary

## Current state
- Rust + iced 0.13 + wgpu 0.19 GPU image viewer/editor for Windows; v0.2.3; external changelog lives in `docs/changelog.md`.
- Source is modular since 2026-06-10: 31-line `main.rs` entry point + `app/` (state+Message / update loop / view / tests) + `theme`, `widgets`, `detail_load`, `session_cache`, `local_edits`, `loading`, `library`, `repo` alongside the original `decode`/`edit`/`viewer`/`lens`/`collection`/`nav` boundaries.
- GPU shader pipeline: 12 real-time adjustments on Lightroom-convention scales (Exposure ±5 EV, everything else ±100; Saturation −100 = grayscale; Temperature ±100 spans 3200K–9800K with non-negative clamp after the Bradford CAT; tone zones are σ=1 Gaussians with 1.5 EV per-band reach and a ±2 EV total clamp), Lensfun distortion/vignetting/TCA, crop preview, icon-based ±90° rotation; slider units convert through shared `edit::*_amount` mappings so the CPU save path and GPU preview cannot drift, and the CPU path mirrors shader math at full resolution including lens correction and the bilinear-sampled 9-tap blur.
- Library and collections: folder/file import, collection CRUD + drag-and-drop (drag state cleared when entering Detail), responsive grids driven by live window width, RAW-orientation-correct thumbnails contained in square slots.
- RAW/SVG Detail loading is staged: embedded preview first, request-id staleness guards, EXIF off the UI path; repo-local `decoded-cache/` persisted decode cache (fingerprint + contract-version validation, import-time serial warming) plus an in-session full-image cache with a 2-entry recent floor and a same-image Library-return short-circuit.
- Committed edits bake into repo-local `local-edits/` files with paired full/thumbnail generations, source-metadata invalidation, and thumbnail repair; bakes stay authoritative offline (candidate path keys + fail-open when the source is absent, fail-closed when present-but-changed), library membership survives offline media, thumbnail bases carry provenance so session state never re-renders onto baked pixels, and preview-window commits bake after navigation via the owed-bake registry; undo/redo stays session-only; Detail status text reports logical base dimensions even when the GPU buffer is downscaled.
- Process: the four gates (test, clippy -D warnings, fmt --check, build) run in GitHub Actions CI on windows-latest; toolchain pinned to 1.94.0; Cargo.lock committed; cargo audit baseline clean (5 transitive informational warnings tracked in the 2026-06-10 devlog).
- 332 unit tests pass in ~14s (dependencies compile at opt-level 2 in dev); same-size-rewrite cache tests force observable mtime changes so fast runners cannot flake them; an env-gated render harness (`PHOTO_RENDER_TUNING_GRID=1`) produces a slider-settings inspection grid.
- Escape in Detail cancels the crop tool (discarding any in-flight drag, which the viewer also refuses to commit after cancellation) before any tab navigation applies.
